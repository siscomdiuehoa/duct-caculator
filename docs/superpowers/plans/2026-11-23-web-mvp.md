# SISCOM Duct Web MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A static web app where a user picks one of four rectangular duct fittings, edits its dimensions, and gets a 3D model, three dimensioned views, sheet area and weight, and DXF/CSV/JSON exports.

**Architecture:** A pure-TypeScript core turns `(fitting id, params in mm)` into one `Model` of ruled sheet panels plus dimension lines. Mesh, projections, DXF, area and weight are all derived from that `Model`. React renders the UI; Three.js renders the mesh.

**Tech Stack:** TypeScript, React 18, Vite, Three.js, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-23-duct-calculator-design.md`

## Global Constraints

- All core values are millimetres; unit conversion happens only in the UI.
- Axes: X width, Y depth, Z up. Views: front X-Z, side Y-Z, plan X-Y.
- No server, no login, no analytics. Library lives in `localStorage`.
- No code, assets or names from DU_DuctLab.
- Default density 7850 kg/m3, default thickness 0.8 mm.
- Weight covers plain sheet only (no flanges, seams or stiffeners).

## Review Focus

1. Non-numeric, empty, zero or negative input: the last valid model stays on screen and the field shows an error.
2. Geometrically impossible input (tee branch wider than main length): validation message, no crash.
3. Switching units must not change the stored millimetre values.
4. Opening a malformed or foreign JSON file: an error message, the current design untouched.
5. `localStorage` unavailable (private mode): the app works, the library is just empty.

## File Structure

- `src/core/types.ts`: `Vec3`, `Panel {name, a: Vec3[], b: Vec3[]}`, `Dim {a, b, label}`, `Model {panels, dims}`, `ParamDef {key, def, min, max, step}`, `FittingDef {id, params, validate(p): string | null, build(p): Model}`.
- `src/core/fittings.ts`: `FITTINGS: FittingDef[]` with ids `straight`, `elbow90`, `reducer`, `tee`; `getFitting(id)`.
- `src/core/measure.ts`: `area(model): number` (mm2), `weightKg(model, t, rho)`, `edges(model): [Vec3, Vec3][]`, `bounds(model)`.
- `src/core/project.ts`: `project(model, view): View2D {segs, dims, w, h}` for `view` in `front | side | plan`.
- `src/core/dxf.ts`: `toDxf(model): string` (R12 ASCII, layers `OUTLINE`, `DIM`).
- `src/core/io.ts`: `toJson`, `fromJson` (throws on bad input), `toCsv`, units table.
- `src/i18n.ts`: `vi` and `en` dictionaries.
- `src/ui/*`: `App.tsx`, `Viewer3D.tsx`, `Views2D.tsx`, `styles.css`.
- `src/core/core.test.ts`: Vitest.
